# Harmony Cheat Sheet (Android / Kotlin / Compose / Room)
1. Open this folder in Android Studio (Koala+), let Gradle sync, run on a device/emulator.
2. Data: app/src/main/assets/harmony.json (exported from the Excel file) -> seeded into Room (harmony.db) on first launch.
3. Sound: generated in code (audio/Synth.kt) – no audio files needed, works offline.
